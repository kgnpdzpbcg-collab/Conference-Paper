# 服务器 GPU 实验结果汇总

实验日期：2026-10-10。本文汇总在同一台服务器 GPU 环境下完成的 CNN1D、ResNet1D 与 CCSAE V0 正式实验，共 **2个数据集 × 3个模型 × 3个随机种子 = 18次运行**。以下性能与耗时均来自服务器正式实验归档。

## 1. 测试集结果

所有指标单位为百分数，报告训练种子42、43、44的**均值 ± 样本标准差**；数据划分固定。每次先由验证集选择最优模型，再对测试集评估。Macro-F1 计算包含全部类别，未预测类别的 F1 按0处理。Balanced Accuracy 为各类别召回率的算术平均。

| 数据集 | 模型 | Accuracy（%） | Macro-F1（%） | Balanced Accuracy（%） |
|---|---|---:|---:|---:|
| SKL | CNN1D | 54.21 ± 2.16 | 51.75 ± 2.32 | 53.53 ± 2.07 |
| SKL | ResNet1D | 86.84 ± 1.05 | 85.63 ± 1.12 | 85.75 ± 1.08 |
| SKL | CCSAE V0 | 65.56 ± 0.97 | 63.71 ± 1.81 | 64.84 ± 1.03 |
| ABL | CNN1D | 65.81 ± 0.22 | 60.40 ± 0.49 | 63.03 ± 0.93 |
| ABL | ResNet1D | 88.17 ± 0.94 | 84.69 ± 0.74 | 85.25 ± 0.88 |
| ABL | CCSAE V0 | 88.96 ± 1.85 | 82.51 ± 1.68 | 83.57 ± 1.74 |

在本轮固定设置下，ResNet1D 在 SKL 上的三项指标均最高，在 ABL 上的 Macro-F1 和 Balanced Accuracy 最高。CCSAE V0 在 ABL 上的 Accuracy 最高，为88.96%，比 ResNet1D 的88.17%高0.79个百分点；其 Macro-F1 为82.51%，低于 ResNet1D 的84.69%。因此，本轮结果不支持将 CCSAE V0 描述为在两套电路上全面优于 ResNet1D。

以上为描述性比较。每个组合只有3个训练种子，未进行显著性检验；这里的标准差反映固定划分下训练随机性的波动，不是重新划分数据得到的标准差，也不是置信区间。

## 2. 数据与共同评估协议

数据来源：[IEEE DataPort：Incipient Fault Dataset for Analog Circuits](https://ieee-dataport.org/documents/incipient-fault-dataset-analog-circuits)，DOI：10.21227/gf4r-5q68。实际输入为每条1000点的单通道响应序列。原数据量纲与类别对应的具体元件状态尚未核实，本文使用类别编号，不将 C0 自动解释为正常状态。

| 数据集 | 类别数 | 去重后总样本数 | 训练集 | 验证集 | 测试集 |
|---|---:|---:|---:|---:|---:|
| SKL | 13 | 3800 | 2660 | 570 | 570 |
| ABL | 11 | 3100 | 2170 | 465 | 465 |

- 全局精确去重后，按类别70%/15%/15%划分；划分种子固定为20261009。训练、验证、测试之间精确重复波形数均为0。
- 仅用训练集所有波形数值拟合一个全局均值与标准差，并原样应用到验证集和测试集；输入转换为 float32，保留完整1000点，不进行逐样本标准化、裁剪、重采样或数据增强。
- 三个模型使用逐元素一致的波形与标签；输入缓存及原始 CSV 的指纹均通过核验。
- 训练种子统一为42、43、44。所有种子均计入汇总，测试结果不参与调参或选模。
- 每组训练全部结束后统一评估测试集：基线组12次，CCSAE组6次。

| 数据集 | 训练集全局均值 | 训练集全局标准差 | C0训练/验证/测试样本数 | 其他每类训练/验证/测试样本数 |
|---|---:|---:|---|---|
| SKL | -0.00781084192968018 | 1.03215027091225 | 140/30/30 | 210/45/45 |

C0测试样本分别只有30条和15条，解释该类表现时应同时检查样本量。精确去重只排除完全相同的波形，不能证明不同采集批次、器件个体之间独立。

## 4. 模型结构与训练设置

### 4.1 CNN1D 与 ResNet1D

CNN1D 使用三个卷积块，通道32/64/128，卷积核7/5/3，各块为卷积、BatchNorm、ReLU和二倍最大池化；之后为全局均值池化及64单元分类头，dropout为0.2。ResNet1D 使用 ResNet-18 基本残差块的2/2/2/2布局，通道32/64/128/256，入口为7点卷积和最大池化，末端为全局均值池化和线性分类层。

| 设置 | CNN1D / ResNet1D |
|---|---|
| 批大小 | 128 |
| 优化器 | AdamW |
| 初始学习率 | 0.001 |
| 权重衰减 | 0.0001 |
| 训练损失 | 按训练标签逆频数加权的交叉熵 |
| 训练轮数 | 最多100轮 |
| 早停 | 验证 Macro-F1 连续15轮未严格提高 |
| 学习率调度 | ReduceLROnPlateau：mode=max，factor=0.5，patience=5 |
| BatchNorm处理 | 每轮训练后，在固定权重下用固定行序的训练集重估统计量，然后验证 |
| 选模 | 验证 Macro-F1 最大；并列保留更早轮次 |

BatchNorm 重估使用 `torch.optim.swa_utils.update_bn`，不更新可训练参数，不读取验证或测试统计量；没有进行 SWA 权重平均。验证和测试均使用 eval 模式。

### 4.2 CCSAE V0

CCSAE V0 使用仓库的独立研究复现模型，包括虚部构造、复数卷积编码器、复数 BatchNorm、特征增强模块、复数投影、幅值解码器与分类器。分类特征由实部和虚部拼接得到；解码器仅用于阶段1的重构学习，阶段2不更新解码器，分类推理也不使用解码器。

| 设置 | SKL | ABL |
|---|---|---|
| 批大小 | 64 | 64 |
| 两阶段优化器 | SGD，momentum=0.9 | SGD，momentum=0.9 |
| 学习率 | 0.0022 | 0.0102 |
| 阶段1轮数 | 100 | 100 |
| 阶段2轮数 | 200 | 200 |
| 阶段1损失 | MSE + 0.0017 × SupCon | MSE + 0.0059 × SupCon |
| SupCon温度 | 0.1 | 0.1 |
| 阶段2损失 | 未加权交叉熵 | 未加权交叉熵 |
| 梯度裁剪 | 最大范数5.0 | 最大范数5.0 |
| 复数特征维数 | 500（实/虚各500） | 300（实/虚各300） |
| 首层大卷积核/通道 | 64 / 20 | 128 / 50 |
| 注意力头数 | 4 | 4 |
| 早停/学习率调度 | 未启用；完整运行100+200轮 | 未启用；完整运行100+200轮 |

阶段1按验证重构与对比总损失最小选择权重；阶段2按验证 Macro-F1 最大选择分类权重，并列保留更早轮次。BatchNorm 保留仓库原有滑动统计方式，没有套用基线的训练集统计重估。重构目标固定为 `paper_signed`，即与带符号的标准化输入做 MSE。幅值解码输出非负，而输入可以为负，这一实现解释存在局限，本轮未改变该目标。

本模型是 CCSAE 的独立 V0 实现，部分结构细节由仓库自行选择，并非原作者官方源码。该结果只能代表本文记录的实现和协议；三种模型的优化器、批大小、类别权重、BatchNorm处理及训练预算并不相同。

| 数据集 | 模型 | 每次训练耗时均值 ± 标准差（秒） | 三种子累计训练耗时（秒） |

| SKL | ResNet1D | 13.79 ± 3.47 | 41.36 |

基线12次正式训练的经过时间为112.78秒；包含四种组合的首轮复演、统一测试和独立核验的完整流程为123.61秒。CCSAE六次正式训练的经过时间为972.60秒，约16分13秒。训练经过时间根据服务器原始计划文件和训练完成文件的时间戳计算，包含任务调度开销，因此不等于单次计时的简单求和。

单次 `train_seconds` 来自运行日志，包含训练期间验证和保存权重等操作；上述时间不包含环境安装、正式运行前的短流程检查或结果回传。模型训练轮数和早停情况不同，耗时记录不能解释为相同训练预算的硬件基准；本轮没有测量推理延迟。

## 7. 验证结果与适用范围

- 两组流程均完成正式训练、统一测试和独立核验，退出码均为0。
- 18次运行的逐行标签、概率、混淆矩阵、分类指标及三种子均值/样本标准差已独立复核。
- 源码快照、数据缓存、去重及原始 CSV 指纹核对通过；选模轮次及基线早停规则核对通过。
- 全部18次运行重载权重后，验证集和测试集的预测概率与保存记录逐元素完全一致。
- 基线全部12次运行的 BatchNorm 统计量可以仅用固定训练集精确重建，模型参数不变；CCSAE阶段2解码器参数保持冻结。
- 基线四种模型/数据集组合的 seed42 首轮损失与验证指标精确复演通过；CCSAE两套电路 seed42 阶段1首轮检查也精确一致。这些检查只覆盖首轮，没有将完整18次训练再次复跑。

数据缺少可核实的采集批次与器件个体分组标识，所以当前结果属于精确去重后的固定分层随机划分实验，不足以直接证明跨批次、跨器件或仿真到实测泛化。模型间的比较也包含各自训练方案的影响，不能把差距全部归因于网络结构。
